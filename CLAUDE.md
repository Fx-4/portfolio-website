# CLAUDE.md — Website Portofolio Haikal

## Project
- React 18 + Vite 5 portfolio website, deployed on Vercel
- Uses Framer Motion, GSAP, AOS for animations
- Space Grotesk + DM Sans typography
- Circular theme reveal animation + mobile responsive navbar

## Commands
- `npm run dev` — start dev server
- `npm run build` — production build

## Conventions
- Bahasa Indonesia for communication (user is Indonesian)
- Commit messages in English

## Obsidian Second Brain
- User has an Obsidian vault connected via Local REST API (MCP)
- Vault structure: Home MOC → Projects, Knowledge Base, HSK
- **IMPORTANT: Do NOT create individual word/vocabulary files in Obsidian** — use consolidated level/category pages instead. Individual files are bloat.
- For bulk file operations (delete hundreds of files), ask user to do it from File Explorer/Obsidian UI — it's instant vs burning thousands of tokens via API
- Nodes should only be for important, meaningful content — not granular items like individual vocabulary words
